소개

오픈소스 음악 생성 모델 ACE-Step 1.5의 공식 무료 데모입니다. 가사와 스타일 태그를 넣으면 보컬곡을 만들며 50개 이상 언어를 지원하고, 생성 속도가 매우 빨라 GPU 할당량 안에서 여러 곡을 시도할 수 있습니다. 4월에 더 큰 XL(4B) 모델이 추가됐고, 공식 웹 UI(acemusic.ai)도 무료로 안내돼 있습니다.

사용 방법

  1. huggingface.co/spaces/ACE-Step/Ace-Step-v1.5 접속 (Hugging Face 로그인 시 할당량 증가)
  2. 스타일 태그(장르·악기·분위기)와 가사, 길이를 입력
  3. Generate 후 결과 오디오를 재생·다운로드
