제약·메모
Antigravity CLI는 설치 시 기존 Gemini CLI의 스킬·MCP 서버·GEMINI.md 설정을 자동으로 가져옴. AI Studio 무료 API 키로 우회하는 방법이 거론되나 무료 API의 Flash 모델 한도는 하루 약 20회 수준으로 보고됨

Gemini CLI 바로가기 ↗

소개

Google 계정 로그인만으로 하루 1,000회 요청을 무료로 쓸 수 있어 가장 인기 있던 무료 터미널 코딩 에이전트였습니다. 2026년 6월 18일부터 무료 개인 계정과 Google AI Pro·Ultra 계정의 요청 처리가 중단되었고, Google은 Antigravity CLI로 이전을 안내하고 있습니다. 오픈소스 도구 자체는 남아 있어 유료 API 키나 기업용 라이선스로는 계속 쓸 수 있습니다.

사용 방법

  1. 무료로 계속 쓰려면 Antigravity CLI(agy)를 설치
  2. Google 계정으로 로그인하면 기존 Gemini CLI 설정이 자동 이전됨
  3. 또는 유료 Gemini API 키를 발급받아 Gemini CLI에 연결
