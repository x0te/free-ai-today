소개

대화만으로 웹앱을 만들고 바로 게시할 수 있는 대표적인 바이브 코딩 앱 빌더입니다. 프론트엔드부터 로그인·데이터베이스(Lovable Cloud)까지 한 번에 구성하고 GitHub로 코드를 내보낼 수 있습니다. 무료 크레딧은 적은 편이라 실제 제품 제작보다는 아이디어 검증과 체험용입니다.

사용 방법

  1. lovable.dev 접속 후 가입
  2. 첫 화면 입력창에 만들 앱을 설명
  3. 미리보기로 확인하며 수정 후 Publish로 lovable.app 주소에 게시
