소개

Google AI Studio의 Build(바이브 코딩) 모드는 만들고 싶은 앱을 문장으로 설명하면 Gemini가 코드를 작성하고 미리보기까지 띄워 주는 브라우저 기반 앱 빌더입니다. 2026년 3월 풀스택 업데이트로 Firebase 로그인·Firestore 데이터베이스, 멀티플레이어, Next.js 지원이 추가되었고 Firebase Studio의 후속 역할을 맡고 있습니다. 설치가 필요 없고 결제 정보 없이 바로 시작할 수 있어 가장 문턱이 낮은 무료 앱 빌더입니다.

사용 방법

  1. aistudio.google.com 접속 후 Google 계정으로 로그인
  2. 왼쪽 메뉴의 Build(앱) 탭에서 만들고 싶은 앱을 한국어로 설명
  3. 미리보기로 확인하며 대화로 수정, 필요하면 Firebase 로그인·DB 추가
  4. Deploy 버튼으로 Cloud Run에 배포하거나 GitHub로 내보내기
