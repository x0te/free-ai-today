소개

DuckDuckGo가 만든 프라이버시 중심 AI 채팅. 계정 없이 여러 회사 모델을 골라 쓸 수 있고, 대화 기록은 서버가 아닌 내 기기에 저장된다. 최근 국내 커뮤니티(클리앙)에서도 '무료 멀티모델 사이트'로 다시 주목받았다.

사용 방법

  1. duck.ai 접속 (또는 DuckDuckGo 앱)
  2. 상단에서 모델 선택
  3. 바로 대화 — 기록은 브라우저에 로컬 저장
