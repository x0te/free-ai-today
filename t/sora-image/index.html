OpenAI 이미지 생성은 ChatGPT(Images 2.5)에서 이용. 기존 Sora 라이브러리 내보내기 기한도 지났다.

Sora 앱 바로가기 ↗

소개

OpenAI의 Sora 앱과 웹에서도 이미지를 만들 수 있었지만, OpenAI가 2026년 3월에 Sora 종료를 발표했다. 앱과 웹은 4월 26일, Sora 2 API는 9월 24일에 끝났다. 무료 사용자의 Sora 이미지·영상 생성은 그보다 앞선 2026년 1월에 이미 막혔다.

사용 방법

  1. 이미지 생성은 chatgpt.com의 Images 메뉴 사용
  2. API가 필요하면 GPT-Image-2.5 모델 사용(유료)
  3. Sora 앱은 더 이상 이용 불가
