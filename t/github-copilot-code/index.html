소개

VS Code, JetBrains, Visual Studio 등 주요 에디터와 GitHub.com, 터미널(Copilot CLI)에서 쓰는 GitHub의 AI 코딩 도우미입니다. 무료 플랜에서도 에이전트 모드와 CLI를 쓸 수 있어 기존 에디터를 바꾸지 않고 AI 코딩을 체험하기 좋습니다. 2026년 6월부터 요금 체계가 토큰 기반 GitHub AI Credits로 바뀌었고, 코드 완성은 별도 한도로 유지됩니다.

사용 방법

  1. GitHub 계정으로 로그인 후 github.com/features/copilot 에서 Free 시작
  2. VS Code 등 에디터에 GitHub Copilot 확장 설치 후 로그인
  3. 채팅 패널에서 Ask/Agent 모드 선택해 사용, 터미널은 Copilot CLI 설치
