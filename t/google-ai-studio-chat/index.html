소개

Google의 개발자용 웹 도구로, Gemini 모델을 채팅 형태로 직접 시험하고 앱까지 만들 수 있습니다. 공식 가격표상 'AI Studio 사용은 모든 제공 지역에서 무료'이며, 2026년 9월 2일 정식 출시된 Gemini 3.8 Flash(가장 똑똑한 Flash, 100만 토큰 컨텍스트)와 8월 13일 출시된 3.7 Flash, 3.6 Flash, 3.5 Flash-Lite 모두 API 무료 등급이 있습니다. Gemini 앱(무료 32K)보다 훨씬 긴 컨텍스트와 온도·시스템 프롬프트 등 세부 설정을 쓸 수 있는 것이 장점입니다.

사용 방법

  1. aistudio.google.com 접속 후 Google 계정 로그인
  2. Chat(Playground)에서 모델을 Gemini 3.8 Flash로 선택
  3. 시스템 지시문·온도 등을 조절하며 대화
  4. 필요하면 'Get API key'로 무료 API 키 발급
