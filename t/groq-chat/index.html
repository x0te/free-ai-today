소개

자체 LPU 칩으로 오픈웨이트 모델을 초고속 추론해 주는 클라우드. 개발자 콘솔의 Playground에서 채팅처럼 바로 쓸 수 있고, 카드 없이 API 키도 발급된다. 응답 속도가 압도적으로 빨라 번역·요약 자동화에 좋다.

사용 방법

  1. console.groq.com 가입
  2. Playground에서 모델(gpt-oss-120b 등) 선택 후 대화
  3. 필요 시 API Keys에서 무료 키 발급
