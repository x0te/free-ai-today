소개

Wix가 인수한 노코드 AI 앱 빌더로, 대화만으로 로그인·데이터베이스·분석 기능이 포함된 앱을 만들어 줍니다. 백엔드 설정 없이 인증과 DB가 기본 내장되어 있어 비개발자가 내부 도구나 간단한 서비스를 만들기 좋습니다.

사용 방법

  1. base44.com 가입
  2. 만들 앱을 설명하면 인증·DB가 포함된 앱이 생성됨
