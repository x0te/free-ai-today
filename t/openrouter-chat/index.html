소개

수백 개 LLM을 하나의 API·채팅 화면으로 묶은 라우터. 모델 ID 끝에 ':free'가 붙은 무료 모델은 카드 등록 없이 웹 채팅이나 API로 바로 쓸 수 있다. 신모델·스텔스 모델이 먼저 무료로 풀리는 경우가 많다.

사용 방법

  1. openrouter.ai 가입
  2. Models에서 가격 'Free' 필터 또는 ':free' 모델 선택
  3. Chat 화면에서 바로 대화하거나 API 키 발급해 사용
