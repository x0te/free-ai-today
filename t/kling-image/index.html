소개

중국 콰이쇼우의 영상·이미지 생성 플랫폼. 영상 모델로 유명하지만 Kling Image 3.0으로 영화 같은 사실적 이미지, 레퍼런스 기반 인물 일관성, 스토리보드 생성도 지원한다. 만든 이미지를 곧바로 영상으로 이어서 만들 수 있다.

사용 방법

  1. kling.ai(구 klingai.com/global)에 가입
  2. AI Images 메뉴에서 Kling Image 3.0 선택
  3. 프롬프트나 레퍼런스를 넣고 생성 (크레딧 소모량 확인)
