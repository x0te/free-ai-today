소개

Lightricks의 AI 영상 제작 스튜디오로, 이미지 생성부터 스토리보드·영상까지 한곳에서 만듭니다. 무료 플랜은 가입할 때 800크레딧을 한 번 주고, 이미지 모델 Z-Image와 자체 영상 모델 LTX-2.5·2.3을 쓸 수 있습니다. Nano Banana·FLUX.2 Pro·ChatGPT Images·Veo·Kling 같은 외부 모델은 유료입니다.

사용 방법

  1. ltx.io/studio에서 'Start for free'로 가입합니다 (800크레딧).
  2. 이미지 생성에서 Z-Image 모델로 프롬프트를 넣어 생성합니다.
  3. 같은 크레딧으로 LTX-2.5 영상도 만들 수 있으니 이미지 위주라면 영상은 아껴 씁니다.
