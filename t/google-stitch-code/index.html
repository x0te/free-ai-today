소개

Stitch는 텍스트나 스케치·스크린샷으로 앱·웹 UI 화면을 생성하는 Google Labs의 AI 디자인 도구입니다. 여러 화면을 한 캔버스에서 만들고 클릭 가능한 프로토타입, HTML/Tailwind·React 코드 내보내기, Figma 붙여넣기를 지원합니다. 유료 요금제가 아예 없어 모든 기능을 무료로 쓸 수 있고, 만든 디자인을 AI Studio·Antigravity로 넘겨 실제 앱으로 이어갈 수 있습니다.

사용 방법

  1. stitch.withgoogle.com 접속 후 Google 계정으로 로그인
  2. 모바일/웹 선택 후 원하는 화면을 문장으로 설명하거나 이미지 업로드
  3. 생성된 화면을 대화로 수정하고 프로토타입으로 연결
  4. Figma로 붙여넣기 또는 HTML·React 코드로 내보내기
