소개

Microsoft Copilot Labs의 실험 기능으로, 자사 음성 모델 MAI-Voice를 이용해 감정이 실린 내레이션·스토리 음성을 만들어 줍니다. 자유롭게 연기하는 Emotive 모드, 여러 목소리로 이야기하는 Story 모드, 원문 그대로 읽는 Scripted 모드를 제공합니다. 크레딧·유료 요금제가 없는 무료 실험 도구입니다.

사용 방법

  1. copilot.microsoft.com/labs/audio-expression 접속
  2. Emotive / Story / Scripted 모드 중 선택
  3. 스크립트 입력 → 목소리·스타일 선택 → 생성 후 MP3 다운로드
