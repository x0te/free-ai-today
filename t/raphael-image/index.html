소개

'가입 없이 무제한'을 내세우는 대표적인 무료 이미지 생성 사이트다. 기본 모드는 대기열만 기다리면 횟수 제한 없이 쓸 수 있고, 로그인하면 매일 주는 무료 크레딧으로 Nano Banana 2/Pro, Seedream 5.0 같은 상위 모델도 조금씩 써 볼 수 있다.

사용 방법

  1. raphael.app 접속 (가입 없이 바로 사용 가능)
  2. 프롬프트 입력 후 Basic 모드로 생성 (대기열 대기)
  3. Nano Banana 등 상위 모델은 로그인 후 일일 크레딧으로 선택
