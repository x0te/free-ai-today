소개

가입 없이 브라우저에서 바로 쓰는 이미지·영상 생성 사이트로, Flux Dev 기반 무료 모델은 횟수 제한 없이 워터마크 없이 받을 수 있다. Nano Banana 2/Pro, GPT-Image-2, Seedream 같은 프리미엄 모델도 올라와 있지만 크레딧이 필요하다.

사용 방법

  1. vheer.com/app/text-to-image 접속
  2. 모델 선택에서 'Free' 표시 모델(Vheer Quality) 선택
  3. 프롬프트 입력 후 무제한 생성·다운로드
