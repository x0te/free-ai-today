소개

Anthropic의 AI 어시스턴트로 글쓰기·분석·코딩 설명에 강합니다. 2026년 9월 28일 공개된 Claude Sonnet 5.5가 무료 플랜 모델로 제공되며(이전에는 6월 30일부터 Sonnet 5), 웹 검색·파일 분석·코드 실행·아티팩트·파일 생성 같은 기능 대부분이 무료에서도 열려 있습니다. 메시지 수가 고정돼 있지 않고 5시간 롤링 세션 한도로 관리됩니다.

사용 방법

  1. claude.ai 접속 또는 Claude 앱 설치
  2. 이메일/Google 계정으로 가입(카드 불필요)
  3. 새 대화에서 바로 질문 — 파일 첨부·웹 검색 사용 가능
  4. 한도 메시지가 뜨면 표시된 시간(최대 5시간) 후 다시 사용

같은 모델을 무료로 쓸 수 있는 다른 곳
