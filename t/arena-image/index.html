소개

AI 모델 성능 순위를 매기는 평가 플랫폼으로, 이미지 아레나에서 두 모델의 결과를 비교 투표하거나(배틀) 원하는 모델을 골라(Direct) 무료로 생성할 수 있다. 배틀에는 출시 전 최신 모델이 익명으로 섞여 나오기도 해 '무료로 최신 모델 써보기' 용도로 인기가 많다. lmarena.ai 주소는 arena.ai로 이전됐다.

사용 방법

  1. arena.ai/image 접속
  2. Battle(익명 비교) 또는 Direct(모델 선택) 모드 선택
  3. 프롬프트 입력 → 결과 저장, 배틀은 투표 후 모델명 공개
