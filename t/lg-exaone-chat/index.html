LG EXAONE API

LG AI Research · 공식

  • K-EXAONE 2.5

LG AI연구원 K-EXAONE 2.5 API 무료 개방 (11/9~): API 키만 발급받으면 무료, 비상업 조건·하루 약 100회 보고됨

무료 한도
API 키 발급 후 무료 호출. 한도는 공식 미확인 — 개인 후기에서 '하루 100회·키 30일 만료'로 보고됨(블로그 1건)
충전 주기
불명 (무료 기간 미공지, 실사용 검증 기간)
워터마크
해당 없음
상업적 이용
불가로 보고됨 (약관상 비상업적 이용만 허용이라는 해석, 보도자료는 '개발·연구 활용'으로 표현)
가입
docs.exaone.ai에서 가입 후 API 키 발급 (카드 불필요로 보도)
한국 사용
가능
제약·메모
모델 규모·컨텍스트 수치가 출처마다 엇갈림(236B vs 750B). 입력 데이터가 학습에 쓰일 수 있다는 후기 있음. 오픈 웨이트는 아직 미공개. 공식 문서 직접 열람은 못 해 보도·후기 기준.

소개

LG AI연구원이 11월 9일 엔비디아 AI 데이 서울 2026에서 K-EXAONE 2.5 API를 자체 플랫폼으로 전면 무료 공개했습니다. 실사용 검증 목적의 개방이라 종료 시점은 공지되지 않았습니다. 개발자용 API라 채팅 UI는 없고 코딩 에이전트·앱에 연결해 씁니다.

사용 방법

  1. docs.exaone.ai에서 계정 만들고 API 키 발급
  2. OpenAI 호환 클라이언트 또는 공식 문서의 엔드포인트로 호출 (30일마다 키 갱신 필요로 보고됨)
