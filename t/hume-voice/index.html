소개

LLM 기반으로 문장의 감정·의도를 이해해 억양과 속도를 조절하는 감정 표현형 TTS 'Octave'를 제공합니다. 무료 플랜에서도 15초 샘플 보이스 클론을 만들 수 있고, 실시간 음성 대화 AI(EVI)도 체험할 수 있습니다. Octave 2는 한국어를 포함한 11개 언어를 지원합니다.

사용 방법

  1. app.hume.ai 에서 무료 가입
  2. Text to Speech(Octave) 메뉴에서 모델을 Octave 2로 선택
  3. 보이스 선택 또는 샘플 업로드로 클론 → 한국어 텍스트 입력 → 생성·다운로드
