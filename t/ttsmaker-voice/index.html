소개

가입 없이 브라우저에서 바로 쓰는 무료 텍스트 음성 변환(TTS) 사이트입니다. 한국어를 포함한 여러 언어와 목소리를 고를 수 있고, 만든 음성 파일을 내려받아 상업적 용도로도 쓸 수 있다고 공식 FAQ에 명시돼 있습니다. 여러 화자가 대화하는 다중 화자 모드도 있습니다.

사용 방법

  1. ttsmaker.com 접속 (가입 불필요)
  2. 언어를 '한국어'로 바꾸고 목소리 선택
  3. 텍스트 입력 → 변환 후 오디오 파일 다운로드
