제약·메모
Qwen3.8-Flash 무료 이벤트는 종료됨. 매일 100크레딧 이벤트는 종료일 미정이었으나 11/6 이후 지속 여부를 공식 문서에서 확인하지 못함(앱에서 확인 필요). Pro 체험은 1인 1계정, 가상머신에서는 체험 불가, 중복 계정은 정지. 팀·엔터프라이즈 계정은 이벤트 제외. [11/14] 11/7(싱가포르 시간)부터 Qoder International 개인 계정(무료 포함)에 스텔스 모델 'Qoduck' 일일 무료 사용량 이벤트가 시작된 것으로 보도됨(출처: 미디어 2곳, 공식 문서는 직접 열람 못 함). 일일 수량·종료일 미공개, 팀·엔터프라이즈 제외, IDE·JetBrains 플러그인·CLI는 이벤트 미지원이라는 보도가 있어 지원 범위는 앱에서 확인 필요. 소개

알리바바가 만든 에이전트형 AI 코딩 도구(국제판)로, 데스크톱 IDE·JetBrains 플러그인·CLI·웹/모바일을 한 계정으로 씁니다. 9월 18일부터 무료 계정도 데스크톱 앱에서 매일 100크레딧을 받을 수 있고, Qwen3.8-Flash 모델은 크레딧 차감 없이 쓸 수 있습니다. Qwen3.8-Flash 크레딧 0 이벤트는 11월 7일(싱가포르 시간 00:00)에 종료됐고, 이후에는 정상 배율(오프피크 시간대 할인 적용)로 크레딧이 차감됩니다.

사용 방법

  1. qoder.com에서 데스크톱 앱을 받아 이메일·Google·GitHub로 가입 (2주 Pro 체험 자동 시작)
  2. 앱 왼쪽 아래 Usage 패널의 선물 아이콘에서 매일 100크레딧 받기 (받을 수 있는 동안)
  3. Qwen3.8-Flash는 이제 크레딧이 차감되므로 잔액을 확인하며 사용
