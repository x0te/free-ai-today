소개

알리바바가 만든 에이전트형 AI 코딩 도구(국제판)로, 데스크톱 IDE·JetBrains 플러그인·CLI·웹/모바일을 한 계정으로 씁니다. 9월 18일부터 무료 계정도 데스크톱 앱에서 매일 100크레딧을 받을 수 있고, Qwen3.8-Flash 모델은 크레딧 차감 없이 쓸 수 있습니다. 9월 30일 끝날 예정이던 Qwen3.8-Flash 무료 이벤트는 종료일 미정으로 연장됐습니다.

사용 방법

  1. qoder.com에서 데스크톱 앱을 받아 이메일·Google·GitHub로 가입 (2주 Pro 체험 자동 시작)
  2. 앱 왼쪽 아래 Usage 패널의 선물 아이콘에서 매일 100크레딧 받기
  3. 모델 선택에서 Qwen3.8-Flash를 고르면 크레딧 차감 없이 사용
