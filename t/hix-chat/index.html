소개

글쓰기 도구로 시작해 멀티모델 채팅·에이전트로 확장한 서비스. 무료 플랜은 카드 없이 '표준 채팅 모델'과 20크레딧을 제공한다. 요금표상 '무제한' 표기는 유료(Max/Pro) 칸에만 있고, 어떤 모델이 표준인지는 공개하지 않는다.

사용 방법

  1. hix.ai 접속 후 가입
  2. HIX Chat에서 표준 모델 선택
  3. 요금표에서 크레딧 잔액 확인
