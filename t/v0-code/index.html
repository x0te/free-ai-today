소개

Vercel이 만든 AI 앱·UI 빌더로 React/Next.js 기반 화면과 풀스택 앱을 프롬프트로 생성합니다. 디자인 모드로 화면을 직접 다듬고 GitHub 동기화, Vercel 원클릭 배포를 지원해 개발자 친화적입니다. 무료는 하루 메시지 수가 적어 짧은 UI 시안 제작에 맞습니다.

사용 방법

  1. v0.app 접속 후 Vercel 계정으로 로그인
  2. 만들 화면이나 앱을 설명
  3. 결과를 수정한 뒤 Deploy로 Vercel에 배포하거나 GitHub에 동기화
