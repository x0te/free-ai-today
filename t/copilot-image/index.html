제약·메모
Copilot 안에서 어떤 이미지 모델이 쓰이는지는 화면에 명확히 나오지 않을 수 있다. 빠른 생성 횟수를 분명히 알고 싶다면 Bing Image Creator가 한도가 더 투명하다.

소개

마이크로소프트 Copilot 앱과 웹에서 대화하며 이미지를 만든다. 마이크로소프트는 2026년 6월 Nano Banana Pro보다 Arena 점수가 높다고 소개한 자체 모델 MAI-Image-2.5를 공개하고 Copilot과 Bing에 순차 적용하고 있다. 예전 Designer의 이미지 생성 기능도 Copilot 쪽으로 합쳐지는 추세다.

사용 방법

  1. copilot.microsoft.com 또는 Copilot 앱 실행 후 로그인
  2. 채팅에 '~ 이미지 그려줘'라고 입력
  3. 결과 이미지를 다운로드하거나 추가 지시로 수정
