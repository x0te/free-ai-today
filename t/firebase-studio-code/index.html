소개

Firebase Studio는 브라우저에서 App Prototyping 에이전트로 풀스택 앱을 만들고 클라우드 개발 환경에서 편집할 수 있던 Google 서비스입니다. 2026년 6월 22일부터 신규 가입과 새 워크스페이스 생성이 막혔고, 기존 사용자는 2027년 3월 22일 종료 전까지 프로젝트를 옮겨야 합니다. Google은 브라우저 프로토타이핑은 AI Studio Build, 코드 중심 개발은 Antigravity로 안내합니다.

사용 방법

  1. 신규 사용자는 Google AI Studio Build 또는 Antigravity 이용
  2. 기존 사용자는 공식 마이그레이션 문서에 따라 프로젝트를 GitHub 또는 AI Studio로 이전
  3. 2027년 3월 22일 전에 데이터 백업
