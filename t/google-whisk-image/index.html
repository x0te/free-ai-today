소개

이미지 여러 장을 섞어 새 이미지를 만드는 Whisk와 Imagen 기반 ImageFX는 구글 Labs의 무료 이미지 도구였다. 2026년 2월 구글이 두 도구를 Flow에 통합한다고 발표했고, 지금 두 주소로 들어가면 flow.google.com으로 넘어간다.

사용 방법

  1. flow.google.com 접속 (기존 Whisk·ImageFX 주소는 자동으로 넘어감)
  2. 프로젝트 안에서 이미지 생성, 레퍼런스 이미지 드래그로 Whisk 방식 합성
  3. 필요하면 기존 Whisk·ImageFX 자산을 Flow 라이브러리로 이전
