Hugging Face Spaces

Hugging Face (커뮤니티/모델사 데모) · 오픈소스

  • Wan 2.2 14B (I2V Fast)
  • MiniMax H3 (오픈웨이트)
  • LTX-2.3 Distilled
  • Wan 2.2 이미지→영상 (FP8·AoTI 가속 Space)
  • Wan 2.2 I2V 커뮤니티 Space

Hugging Face Spaces 무료: 무료 계정 하루 ZeroGPU 5분 → Wan 2.2 14B Fast 480p 5초 약 4개 (MiniMax H3는 1~2개)

무료 한도
ZeroGPU 일일 GPU 시간: 비로그인 2분, 무료 계정 5분 (PRO 40분). Wan 2.2 14B Fast: 5초(81프레임) 480p·6스텝 기준 1개당 GPU 약 70초 → 무료 계정 하루 약 4개(3.5초 기본값이면 약 6개). MiniMax H3: 1회 최소 60초 이상 예약 → 하루 1~2개 수준

소개

오픈소스 영상 모델을 Hugging Face의 무료 GPU(ZeroGPU) 데모로 돌리는 방법입니다. 가장 인기 있는 Wan 2.2 14B Fast 이미지→영상 Space, 2026년 7월 공개돼 영상 순위 상위권에 오른 오픈웨이트 MiniMax H3(사운드 동시 생성) 공식 Space, Lightricks LTX-2.3 Space 등을 브라우저에서 무료로 쓸 수 있습니다. 한도는 계정 등급별 하루 GPU 사용 시간으로 정해집니다.

사용 방법

  1. huggingface.co 무료 가입 후 로그인 (GPU 한도 2분→5분)
  2. Spaces에서 'wan2-2-fp8da-aoti-faster'(Wan 2.2) 또는 'MiniMaxAI/MiniMax-H3-Turbo-Lora' 검색
  3. 이미지·프롬프트 입력 후 Generate — 한도 초과 시 다음 날 리셋
