소개

OpenAI의 코딩 에이전트 Codex는 데스크톱 앱, CLI, IDE 확장, 웹(클라우드)에서 코드를 읽고 수정하며 명령을 실행합니다. 공식 요금 안내상 ChatGPT Free 플랜에도 Codex가 포함되지만, 무료는 ChatGPT 데스크톱 앱에서 GPT-6 Luna로 '빠른 코딩 작업'을 하는 범위로 한정됩니다. 무료 한도는 공개되지 않았고 첫 실전 작업에서 금방 막힌다는 평이 많아 맛보기 용도로 보는 것이 좋습니다.

사용 방법

  1. chatgpt.com 무료 계정으로 로그인
  2. ChatGPT 데스크톱 앱을 설치하고 Codex를 연다 (무료는 순차 롤아웃)
  3. 작업 폴더를 열고 간단한 수정 작업부터 지시
