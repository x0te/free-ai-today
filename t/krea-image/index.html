소개

타이핑하거나 그리는 즉시 이미지가 바뀌는 실시간 생성으로 유명한 크리에이티브 툴. 무료 플랜에서도 새 자체 모델 Krea 2와 실시간 모델, 에이전트, 소규모 LoRA 학습, 2K 업스케일을 쓸 수 있다.

사용 방법

  1. krea.ai 가입 (카드 불필요)
  2. Image에서 무료로 쓸 수 있는 모델(Krea 2 Turbo, Flux.1 Dev, Z Image 등)을 선택 — 모델마다 유닛 소모량이 다름
  3. 프롬프트 입력 후 생성, 실시간 캔버스는 Realtime 메뉴에서
