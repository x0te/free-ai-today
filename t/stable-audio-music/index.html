소개

Stability AI의 공식 음악 생성 웹 스튜디오입니다. 프롬프트로 완성 믹스를 한 번에 만들거나(FULL MIX), 에이전트가 악기별 트랙을 나눠 녹음하는 멀티트랙 모드로 만든 뒤 트랙 추가·재생성·구간 교체로 다듬을 수 있습니다. 믹싱·이펙트·바운스·내보내기는 크레딧이 들지 않습니다. 보컬곡보다는 BGM·연주곡에 강합니다.

사용 방법

  1. stableaudio.com 에서 무료 가입
  2. 프롬프트 입력 → FULL MIX(4크레딧) 또는 MULTI-TRACK(6크레딧) 선택, 길이 선택 후 START
  3. 필요한 트랙만 재생성·교체한 뒤 믹스를 내보내기(무료)
