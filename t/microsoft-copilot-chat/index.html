소개

Microsoft의 무료 AI 비서로 웹, Windows, Edge, 모바일에서 쓸 수 있습니다. GPT-5 기반 Smart 모드가 질문 난이도에 따라 빠른 답변과 깊은 추론(Think Deeper)을 오가며, Bing 웹 검색(출처 링크)·이미지 생성·음성 대화를 무료로 지원합니다. 2026년 8월 18일 소비자용 Copilot과 Microsoft 365 Copilot 앱이 하나로 통합되면서 무료 Deep Research·AI 팟캐스트·그룹 채팅·Copilot Labs·Mico 캐릭터가 종료됐고, 심층 리서치 후속 기능(Researcher)은 유료 Microsoft 365 Premium 전용이 됐습니다.

사용 방법

  1. copilot.microsoft.com 접속 또는 Windows의 Copilot 앱/Edge 사이드바 열기
  2. 로그인 없이 바로 질문(기록 저장·이미지 생성은 Microsoft 계정 로그인)
  3. 복잡한 질문은 Smart/Think Deeper 모드 선택
