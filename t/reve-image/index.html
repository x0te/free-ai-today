무료 계정은 모델 학습 활용에 기본 동의 상태이고, 거부(옵트아웃)는 유료 Lite·Pro에서만 가능. 유료 Lite $7.99/월 = 무료 기본량의 5배, Pro $19.99/월 = 100배 + 영상 크레딧. 공식 요금·도움말 페이지가 봇 차단으로 직접 열람되지 않아 2차 요약 기준.

소개

글자 표현과 프롬프트 충실도로 주목받은 이미지 모델 Reve의 공식 앱입니다. 생성한 이미지를 채팅하듯 고쳐 나가는 편집 기능이 있습니다. 무료 플랜은 가입할 때 한 번 주는 크레딧과 매일 다시 채워지는 기본 크레딧으로 쓰며, 정확한 양은 공개하지 않습니다.

사용 방법

  1. app.reve.com에서 가입합니다 (가입 크레딧 지급).
  2. 프롬프트로 이미지를 만들고, 채팅으로 수정 지시를 이어 갑니다.
  3. 크레딧을 다 쓰면 다음 날 충전을 기다립니다.
