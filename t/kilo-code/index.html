Kilo Code 무료: Auto Free(kilo-auto/free)가 무료 모델로 자동 연결, 카드 없이 VS Code·JetBrains·CLI에서 사용 (한도는 상위 제공사 속도 제한)

무료 한도
Auto Free와 (free) 표시 모델은 사용료 0원. 공식 사용량 수치는 없고 상위 제공사 속도 제한이 걸릴 수 있음(제3자 집계로 시간당 약 200요청 보고). 완전 무료로 쓰려면 에이전트 채팅·자동완성·백그라운드 작업 세 곳 모두 무료 모델로 설정해야 함(자동완성은 Mistral Codestral 무료 키를 직접 넣는 방식)

공식 안내: Auto Free는 프롬프트·출력을 보관하거나 서비스 개선에 쓰는 제공사로 보낼 수 있으니 개인·기밀 정보는 피할 것. NVIDIA 엔드포인트는 체험용이며 사용 기록이 수집됨. 무료 모델 목록은 수시로 바뀜. 예전의 '첫 충전 시 $20 보너스'는 최신 문서에서 빠짐.

소개

오픈소스 AI 코딩 에이전트(VS Code·JetBrains 확장, CLI)로, 자체 게이트웨이에서 무료 모델을 제공합니다. 기본 무료 옵션인 Auto Free는 그때 쓸 수 있는 무료 모델로 요청을 자동 배분하고, 모델 선택기에서 'free'로 검색하면 개별 무료 모델도 고를 수 있습니다. 유료 모델은 크레딧을 충전해야 합니다.

사용 방법

  1. VS Code·JetBrains에서 Kilo Code 확장 설치 (또는 Kilo CLI)
  2. Kilo 계정으로 로그인
  3. 모델에서 Auto Free 선택, 또는 'free'로 검색해 무료 모델 고르기
