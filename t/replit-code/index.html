소개

브라우저에서 코딩·실행·배포까지 한 번에 되는 클라우드 개발 환경이며, Replit Agent가 프롬프트로 앱을 만들어 줍니다. 무료 Starter 플랜은 빠른 수정 위주의 Lite build 모드와 내장 데이터베이스, 슬라이드·영상·애니메이션 제작 기능을 제공합니다. 완전 자율형 Full build는 유료 플랜 전용입니다.

사용 방법

  1. replit.com 가입
  2. 홈 입력창에 만들 앱을 설명하고 Agent 실행(Lite build)
  3. 완성 후 Publish로 게시(무료 1개, 30일)
