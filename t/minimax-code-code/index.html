소개

MiniMax의 데스크톱 AI 에이전트 앱(macOS·Windows, CLI도 제공)으로 코딩 모드와 업무 모드를 함께 씁니다. 앱에서 매일 출석 체크를 하면 포인트가 쌓이고, 이 포인트로 코딩·딥 리서치·프레젠테이션·이미지·영상 생성 등에 쓸 수 있습니다. 꾸준히 쓰려면 M Plan(Token Plan 기반) 구독이 주력입니다.

사용 방법

  1. agent.minimax.io에서 MiniMax Code 데스크톱 앱 설치 후 로그인
  2. 앱에서 매일 출석 체크로 포인트 적립
  3. Coding 모드로 프로젝트 폴더를 연결해 작업 요청
