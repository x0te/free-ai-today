소개

채팅·이미지·영상 AI를 한 사이트에 모은 서비스의 이미지 생성 기능입니다. 무료 Basic 플랜은 기본 모델로 하루 이미지 5장을 만들 수 있고, 가입 시 30크레딧과 출석 체크 크레딧을 따로 줍니다. Nano Banana Pro, GPT Image 2.5, Seedream 같은 모델은 크레딧을 씁니다.

사용 방법

  1. easemate.ai에서 가입합니다 (30크레딧 지급).
  2. AI Image Generator에서 기본 모델을 고르면 하루 5장까지 무료입니다.
  3. 프리미엄 모델은 크레딧이 차감되니 선택 전에 차감량을 확인합니다.
