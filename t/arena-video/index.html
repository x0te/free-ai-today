소개

Arena의 영상 배틀 모드. 프롬프트(또는 이미지)를 넣으면 익명 영상 모델 두 개가 각각 5~8초 영상을 만들고, 투표 후 모델명이 공개된다. 모델을 직접 고를 수는 없지만 상용 최신 영상 모델을 무료로 맛볼 수 있다.

사용 방법

  1. arena.ai 로그인
  2. 입력창 옆 필름 릴(영상) 아이콘 클릭
  3. 프롬프트 입력 → 두 영상 비교 후 투표하면 모델명 공개
