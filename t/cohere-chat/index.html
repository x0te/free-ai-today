소개

캐나다 Cohere의 개발자 대시보드로, 가입하면 무료 체험(trial) API 키가 바로 나옵니다. 체험 키로 Command A 계열을 포함한 모든 모델과 API를 쓸 수 있고, 대시보드 플레이그라운드에서 채팅처럼 시험해 볼 수 있습니다. 체험 키는 시제품·테스트용입니다.

사용 방법

  1. dashboard.cohere.com에서 가입 (체험 키 자동 발급)
  2. Playground에서 Command A 등 모델 선택 후 대화
  3. API Keys 메뉴에서 체험 키를 복사해 다른 앱에 연결
