제약·메모
Z.ai는 2025년 1월 미국 상무부 수출통제 명단(Entity List)에 오름. 중국 기업 서비스이므로 민감 정보 입력 주의. 개발자는 API의 GLM-4.7-Flash 무료 사용 가능.

Z.ai 바로가기 ↗

소개

중국 Z.ai(구 Zhipu AI)의 GLM 모델을 쓰는 챗봇·에이전트 서비스입니다. chat.z.ai에서 로그인 없이 멀티모달 GLM-5.3-Flash로 대화할 수 있고, 2026년 8월 14일 공개된 GLM-5.3 등 최신 모델을 제공합니다. 코딩·웹페이지 생성·장기 에이전트 작업에 강점이 있으며, API에서는 GLM-4.7-Flash가 무료입니다.

사용 방법

  1. chat.z.ai 접속(로그인 없이 바로 대화 가능)
  2. 모델 메뉴에서 GLM-5.3 / GLM-5.3-Flash 선택
  3. 대화·코딩·웹페이지 생성 요청 입력
