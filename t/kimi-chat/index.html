소개

중국 Moonshot AI의 챗봇입니다. 2026년 7월 공개된 Kimi K3(100만 토큰 컨텍스트, 이미지·영상 이해)가 최신 모델이지만, 공식 도움말상 K3·K3 Agent Swarm·Deep Research·PPT·웹사이트 배포·Kimi Code는 모두 유료 멤버십 크레딧을 차감하는 기능입니다. 무료 계정은 일반 채팅 위주로 쓸 수 있으며, 커뮤니티 보고로는 K2.6 모델이 응답하고 K3 풀 버전 요청은 차단됩니다.

사용 방법

  1. kimi.com 접속 후 계정 로그인
  2. 무료로는 기본 채팅 모델로 질문·문서 업로드
  3. K3·에이전트·Deep Research는 유료 멤버십 가입 후 사용
