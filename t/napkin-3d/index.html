소개

글을 붙여넣고 문단을 선택하면 인포그래픽, 플로차트, 마인드맵, 차트 같은 시각 자료를 자동으로 만들어 주는 도구입니다. 만든 결과는 색·아이콘·레이아웃을 자유롭게 편집할 수 있어서 보고서나 발표 자료에 넣을 도식을 빠르게 만들 때 좋습니다. 슬라이드 생성 기능(베타)도 있습니다.

사용 방법

  1. napkin.ai 에 가입합니다.
  2. 글을 붙여넣거나 문서 파일을 불러온 뒤 시각화할 문단을 선택하고 번개(생성) 아이콘을 누릅니다.
  3. 여러 디자인 후보 중 하나를 골라 편집하고 PNG나 PDF로 내보냅니다.
