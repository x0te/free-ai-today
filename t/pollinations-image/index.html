Pollinations: 퀘스트로 받는 무료 'Quest Pollen'으로 Flux·Z-Image·GPT Image 2 등 (Nano Banana·Seedream은 유료 Pollen 전용)

무료 한도
가입한 뒤 Quests 대시보드의 퀘스트(계정 활동·커뮤니티 기여·앱 제출 등)를 완료하면 Quest Pollen을 받는다. 정기 무료 지급은 없고 보상량은 퀘스트마다 다르다. Quest Pollen은 '유료 전용'이 아닌 모델에만 쓸 수 있다. 장당 가격(1 Pollen ≈ $1): Flux.1 Schnell 0.002, Z-Image Turbo 0.004, FLUX.2 Klein 4B 0.005, Flux 1.1 Pro·Kontext Pro 0.03

소개

오픈소스로 운영되는 멀티모달 생성 API·웹 플레이그라운드다. 예전엔 키 없이 무제한 호출이 가능했지만 지금은 Pollen 크레딧제($1≈1 Pollen)로 바뀌었다. 퀘스트·티어로 받는 무료 Pollen으로 유료 전용이 아닌 모델을 쓸 수 있어 개발자·봇 제작용으로 인기가 많다.

사용 방법

  1. enter.pollinations.ai 가입
  2. Quests 대시보드에서 퀘스트 완료 후 Quest Pollen 수령
  3. API(gen.pollinations.ai)나 Pollinations 계정 연동(BYOP) 웹앱에서 유료 전용이 아닌 모델을 골라 생성
