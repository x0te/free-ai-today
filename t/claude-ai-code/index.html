소개

Claude 무료 플랜에서는 대화로 코드를 작성·디버깅하고, Artifacts 기능으로 만든 웹앱·게임·차트를 채팅 옆에서 바로 실행해 볼 수 있습니다. 만든 Artifact는 링크로 게시하거나 다른 사람 것을 리믹스할 수 있고, 코드 실행으로 파일 생성·편집도 가능합니다. 다만 터미널 코딩 에이전트인 Claude Code는 Pro 이상 유료 플랜 전용입니다.

사용 방법

  1. claude.ai 접속 후 이메일 또는 Google 계정으로 가입
  2. 만들고 싶은 앱·도구를 설명하면 Artifact로 코드와 실행 화면이 생성됨
  3. 대화로 수정 후 Publish로 링크 공유
