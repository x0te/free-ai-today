소개

UC 버클리 Chatbot Arena에서 출발해 2026년 1월 'Arena'(arena.ai)로 이름을 바꾼 모델 비교 플랫폼. 배틀 모드에서는 익명 모델 두 개의 답을 받아 투표하고, Direct 모드에서는 모델을 골라 바로 대화한다. 출시 전 스텔스 모델이 익명으로 섞여 나오는 경우가 많아 신모델을 가장 먼저 무료로 써볼 수 있는 곳.

사용 방법

  1. arena.ai 접속
  2. 상단에서 Battle / Side by Side / Direct 중 모드 선택
  3. Direct에서 원하는 모델을 고르거나 Battle에서 익명 두 모델 답변 비교 후 투표
