소개

카카오톡 채팅 탭에서 바로 ChatGPT를 쓰는 OpenAI·카카오 제휴 서비스(만 14세 이상). 카카오맵·예약 등과 연동되고, 무료 계정으로도 이미지 생성·재생성이 된다. 현재 청년 대상 Plus 2개월 무료 프로모션이 진행 중.

사용 방법

  1. 카카오톡 채팅 탭에서 'ChatGPT' 진입 후 ChatGPT 계정 연결
  2. 프로모션은 모바일에서 카카오 프로모션 페이지 접속 → 채널 추가·동의 후 참여
  3. 적용 즉시 Plus 2개월 사용 (종료 후 자동결제 없음)
