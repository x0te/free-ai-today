Bing Video Creator (Sora 2)

Microsoft · Wrapper

  • Sora 2 (Azure OpenAI)

Bing Video Creator 무료: Sora 2로 8초 영상 — 빠른 모드 10회 + 표준 속도(수 시간 대기) 무제한. 단 Azure의 Sora 2가 2026-10-15 은퇴 예정

로그인 시 빠른(Fast) 생성 10회 무료, 이후 빠른 생성은 1회당 Microsoft Rewards 100포인트, 아니면 표준(Standard) 속도로 무제한. 영상 길이 8초, 9:16/16:9

제약·메모
OpenAI의 Sora 앱·API는 종료(API 2026-09-24)됐지만 Bing은 Azure OpenAI의 Sora 2를 쓴다. 2026-09-30 기준 bing.com/images/create 페이지 설정에 Sora 영상 모델(8초, Standard/Fast)이 그대로 노출됨. Microsoft Foundry 모델 은퇴 일정상 sora-2(2025-12-08)는 2026-10-15 은퇴, 대체 모델 없음 → 10월 중순 이후 중단 가능성 큼. 실제 생성 성공 여부는 직접 확인 못 함. 표준 속도는 1개에 수 시간 걸릴 수 있음.

Bing Video Creator (Sora 2) 바로가기 ↗

소개

Bing Video Creator는 2025년 6월 Sora로 무료 영상 생성을 열었고 2026년 3월 Sora 2로 업그레이드됐습니다. 하지만 OpenAI는 Sora 앱을 2026년 4월 26일, Sora 2 API를 9월 24일에 종료했고, 2026-09-29 확인 시 Bing의 영상 생성 경로(ai-video-generator)가 이미지 생성기로 리다이렉트됐습니다. 공식 종료 공지는 찾지 못했습니다.

사용 방법

  1. bing.com/images/create 접속 후 Microsoft 계정으로 로그인
  2. 생성 유형에서 Video(동영상)를 고르고 프롬프트 입력
  3. 속도 Fast(무료 10회) 또는 Standard를 고른 뒤 생성, 완료 알림이 오면 다운로드
