소개

OpenAI가 공개한 TTS 데모 사이트로, 보이스를 고르고 '차분한 상담원', '스포츠 캐스터' 같은 말투 지시문(Vibe)을 붙여 문장을 읽게 할 수 있습니다. 가입 없이 바로 들어보고 저장할 수 있어 성우 톤 테스트에 좋습니다. 한국어 문장도 읽을 수 있습니다(Whisper 지원 언어 수준).

사용 방법

  1. openai.fm 접속 (가입 불필요)
  2. 보이스와 Vibe(말투) 프리셋 선택 또는 직접 지시문 작성
  3. 한국어 스크립트 입력 → Play로 듣고 Download로 저장
