소개

SeaArt는 이미지·영상·캐릭터 챗을 제공하는 크리에이티브 커뮤니티로, 영상 메뉴에서 Seedance 2.5·MiniMax H3·Kling 등과 자체 모델을 내세웁니다. 무료 계정은 매일 스태미나(크레딧)를 받지만 고해상도 영상 하나가 기본 이미지 수십 장 분량을 소모한다고 리뷰됩니다. 무료 계정의 영상 모델 접근 범위는 공식적으로 확인하지 못했습니다.

사용 방법

  1. seaart.ai 가입
  2. Make Videos에서 모델 선택 (표시되는 스태미나 소모량 확인)
  3. 일일 스태미나 안에서 생성
