소개

프랑스 Mistral AI의 챗봇 Le Chat이 2026년 5월 말 'Vibe'로 이름을 바꾸고 업무(Work)·코딩(Code)·채팅(Chat) 모드를 가진 통합 에이전트로 개편됐습니다. 무료 플랜에서도 웹·모바일 대화, 웹 검색, 이미지 생성, 100개 이상 커넥터, 제한적 코딩 세션을 쓸 수 있고 매월 $10 상당의 API 크레딧이 제공됩니다. 유럽 기업이라 개인정보 보호 측면에서 선호되기도 합니다.

사용 방법

  1. chat.mistral.ai 접속 또는 Vibe(구 Le Chat) 앱 설치
  2. 계정 가입 후 Chat 모드에서 대화
  3. 웹 검색·이미지 생성은 입력창 도구에서 선택
