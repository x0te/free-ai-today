소개

질문하면 웹을 검색해 출처(인용)를 붙여 답해 주는 AI 검색 엔진입니다. 로그인 없이도 기본 검색을 쓸 수 있고, 무료 계정은 기본 모델로 제한되며 고급 검색·딥리서치는 하루 사용량이 제한됩니다. 무료 AI 브라우저 Comet(Windows·macOS·모바일)도 함께 제공합니다.

사용 방법

  1. perplexity.ai 접속(로그인 없이 바로 검색 가능)
  2. 질문 입력 → 답변 아래 출처 링크로 원문 확인
  3. 계정 가입 후 딥리서치 모드를 선택하면 하루 제한 횟수 내에서 보고서 생성
