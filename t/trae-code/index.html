무료 요청은 일반(Standard) 대기열이라 피크 시간에 대기 발생. 모델 직접 선택 불가(Auto 모드만). 공식 문서 기준 TraeCode SOLO 모드는 유료 플랜 전용(무료 미포함). 중국판(trae.cn)은 별도 운영되며 국산 모델 중심, 매일 출석 포인트(200→150)로 쓰는 방식이라는 보고가 있음(V2EX, 2026-09). 데이터 수집·개인정보 정책에 대한 우려가 커뮤니티에서 제기됨

소개

ByteDance가 만든 VS Code 기반 AI IDE로, 채팅·에이전트 기능과 자율 개발 모드인 SOLO를 제공합니다. 무료 플랜에서도 월 5,000회 자동완성과 제한된 에이전트 사용량, 클라우드 작업 2개 동시 실행을 지원합니다. 2026년 2월 토큰 기반 4단계 요금제로 바뀐 뒤 무료는 모델 선택 없이 Auto 모드만 가능합니다.

사용 방법

  1. trae.ai에서 IDE 다운로드
  2. 계정 가입 후 VS Code 설정 가져오기
  3. 채팅/Builder 모드에서 작업 지시 (SOLO 모드는 유료 플랜 전용)
