ChatGPT 무료: GPT-5.6 Luna 텍스트 대화 무제한 + Think 버튼, 대신 한국에서도 답변 하단 광고 노출

무료 한도
텍스트 대화 무제한(남용 방지 장치 적용), Think 버튼으로 추론 강화 가능. 파일 업로드·이미지 생성·음성·데이터 분석 등 도구는 별도 한도(이미지는 커뮤니티 보고 기준 하루 2~3장 수준)
충전 주기
텍스트는 무제한 / 도구 한도는 롤링 윈도우(불명확)
워터마크
없음 (텍스트 출력)

제약·메모
2026년 6월 19일부터 한국에서도 무료·Go 요금제 성인 로그인 사용자에게 답변 하단 'Sponsored' 카드형 광고가 표시됨. 유료 GPT-5.6 Sol·추론량 슬라이더는 Plus 이상. GPT-6 Luna는 무료 계정의 경우 데스크톱 앱에서만 제공.

소개

가장 널리 쓰이는 범용 AI 챗봇입니다. 2026년 8월 6일부터 무료·Go 사용자의 기본 모델이 GPT-5.6 Luna로 바뀌면서 일반 텍스트 대화의 메시지 한도가 사라졌고, 어려운 질문은 'Think' 버튼으로 더 오래 추론시킬 수 있습니다. 9월 22일 공개된 GPT-6 Luna는 무료 사용자도 데스크톱 앱에서 쓸 수 있습니다. 파일 업로드·이미지 생성·음성 등 도구는 여전히 별도 한도가 있습니다.

사용 방법

  1. chatgpt.com 접속 또는 모바일/데스크톱 앱 설치
  2. 무료 계정으로 로그인(무제한 텍스트 대화는 로그인 필요)
  3. 어려운 질문은 입력창의 'Think' 버튼을 켜고 질문
  4. GPT-6 Luna를 써보려면 ChatGPT 데스크톱 앱에서 모델 선택
