소개

확산(diffusion) 방식 언어모델 Mercury를 만드는 Inception Labs의 API 플랫폼입니다. 10월 8일부터 새 계정마다 1억 토큰을 무료로 주며(기존 1천만), 결제 정보 없이 API 키를 받아 쓸 수 있습니다. 브라우저에서 써 보는 Mercury Chat도 따로 있습니다.

사용 방법

  1. platform.inceptionlabs.ai에서 가입 후 API 키 발급
  2. OpenAI 호환 클라이언트에 base URL https://api.inceptionlabs.ai/v1 과 키 입력
  3. 모델 mercury-2.5 선택 (브라우저 체험은 chat.inceptionlabs.ai)
