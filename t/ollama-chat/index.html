소개

로컬 LLM 실행기로 유명한 Ollama의 클라우드 추론 서비스입니다. ollama.com에 가입하고 앱이나 CLI에서 로그인하면 일부 스타터 모델을 내 PC가 아닌 Ollama 서버에서 돌릴 수 있습니다. 무료 사용량은 소량이고, 전체 모델은 사용량 크레딧을 사야 열립니다.

사용 방법

  1. ollama.com 가입 후 Ollama 앱 설치
  2. 앱 또는 터미널에서 ollama signin 으로 로그인
  3. 클라우드 태그가 붙은 스타터 모델 선택 후 대화
