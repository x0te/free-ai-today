소개

오픈소스 음성 모델의 공식 데모를 브라우저에서 바로 써볼 수 있습니다. Qwen3-TTS는 한국어 포함 10개 언어와 3초 샘플 보이스 클론을, Resemble AI의 Chatterbox Multilingual은 한국어 포함 23개 언어와 클론을 지원합니다(Kokoro는 가볍고 빠르지만 한국어 미지원). 모델이 Apache 2.0/MIT 라이선스라 직접 설치하면 상업적으로도 쓸 수 있습니다.

사용 방법

  1. huggingface.co/spaces/Qwen/Qwen3-TTS 또는 huggingface.co/spaces/ResembleAI/Chatterbox-Multilingual-TTS 접속
  2. 언어를 Korean으로 선택하고 (클론 시) 참고 음성 3~10초 업로드
  3. 텍스트 입력 → Generate → 결과 오디오 다운로드
