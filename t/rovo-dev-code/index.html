소개

Atlassian의 AI 코딩 에이전트로 터미널(Rovo Dev CLI)·VS Code 확장·코드 리뷰에서 씁니다. 무료 Rovo Dev Free는 Rovo Dev가 켜진 Jira 사이트마다 사용자당 월 350크레딧을 주며, 공식 추산으로 CLI 작업 1~10개 또는 코드 리뷰 2~8회 분량입니다. 다 쓰면 다음 결제 주기까지 멈춥니다.

사용 방법

  1. Atlassian 계정으로 Rovo Dev Free가 켜진 Jira 사이트에 멤버로 참여
  2. Rovo Dev CLI 또는 VS Code 확장 설치 후 로그인
  3. Rovo Dev 사용량 화면에서 남은 크레딧 확인
