소개

Google의 에이전트 중심 개발 플랫폼으로 IDE, 터미널용 Antigravity CLI(agy), 에이전트 매니저로 구성됩니다. 2026년 6월 Gemini CLI를 흡수했고, 무료 개인 요금제에서도 Gemini뿐 아니라 Claude Sonnet·Opus 4.6과 gpt-oss-120b를 고를 수 있는 것이 큰 장점입니다. 에이전트가 계획을 세우고 여러 파일을 수정하며 브라우저로 결과를 확인하는 방식이라 바이브 코딩에 적합합니다.

사용 방법

  1. antigravity.google에서 Windows/macOS/Linux용 앱 다운로드
  2. 개인 Google 계정으로 로그인하고 Individual(무료) 플랜 선택
  3. 에이전트 매니저에서 모델(Gemini 3.1 Pro, Claude Opus 4.6 등)을 고르고 작업 지시
  4. 터미널에서 쓰려면 Antigravity CLI(agy) 설치 후 같은 계정으로 로그인
