소개

웹 조사·문서·슬라이드·웹사이트 제작 등을 스스로 수행하는 범용 AI 에이전트입니다. 무료 플랜은 Chat 모드와 Agent 모드의 Manus 2.0 Lite를 쓸 수 있고 매일 300크레딧이 새로 채워집니다. 일일 크레딧은 이월되지 않고, 무료 사용자는 한 달에 1,500크레딧까지만 일일 크레딧을 쓸 수 있습니다.

사용 방법

  1. manus.im에서 가입
  2. Agent 모드에서 Manus 2.0 Lite로 작업 요청 (일일 크레딧 사용)
  3. 매일 한국 시간 오전 9시 300크레딧 재충전 (남은 일일 크레딧은 소멸)
