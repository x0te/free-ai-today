소개

마이크로소프트의 무료 이미지 생성기. 지금은 자체 모델 MAI-Image-2.5-Flash(조명, 풍경, 사실감)와 MAI-Image-2e(빠르고 스타일화된 이미지)를 쓰며, 한 번에 4장을 만든다. 빠른 생성을 다 쓴 뒤에도 느린 대기열로 계속 만들 수 있어 사실상 무제한이다.

사용 방법

  1. bing.com/images/create에 Microsoft 계정으로 로그인
  2. 모델(MAI-Image-2.5-Flash 또는 MAI-Image-2e)을 고르고 프롬프트 입력
  3. 4장 중 원하는 결과를 다운로드하거나 편집
