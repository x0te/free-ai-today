YouTube Shorts / YouTube Create 바로가기 ↗

소개

YouTube Shorts의 'Remix with Gemini'와 YouTube Create 앱에서 Gemini Omni Flash 영상 생성을 추가 비용 없이 쓸 수 있다. 텍스트·사진·음성으로 10초 클립을 만들어 바로 쇼츠로 올릴 수 있고, YouTube Create 앱에서는 결과 파일을 따로 보관할 수도 있다.

사용 방법

  1. YouTube 모바일 앱에서 '+' → Shorts 만들기 (또는 YouTube Create 앱 실행)
  2. 생성 도구에서 'Remix with Gemini' 선택
  3. 텍스트·사진·음성 입력 후 생성 — 약 20~40초 뒤 10초 클립 완성
