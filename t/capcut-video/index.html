제약·메모
Seedance 2.5는 4~30초, 480p/720p. 영상 1개당 크레딧 소모량이 공개 페이지에 없어 실제 개수는 계정에서 확인 필요. 공식 페이지 안내가 엇갈림: 'Seedance 2.5는 구독 계정부터 지역별로 순차 적용'이라고 하면서 '무료 일일 크레딧으로 시작 가능'이라고도 적음. 같은 회사의 Dreamina에서는 크레딧이 있어도 무료 계정이 영상 생성 시 구독 결제창을 만났다는 보고(2026-08)가 있어, 무료로 실제 생성되는지 확인되지 않음. CapCut은 Seedance 제작사(ByteDance) 계열 앱이라 공식 서비스로 분류할 수도 있음.

소개

CapCut(캡컷)은 ByteDance의 영상 편집기로, 같은 회사의 Seedance 2.5(최대 30초 원테이크)·2.0 모델을 웹·PC·모바일에서 바로 쓸 수 있게 넣었습니다. 신규 가입 시 200크레딧 웰컴 보너스를 주며 'Seedance 영상 생성을 무료로 체험'하라고 안내합니다. 생성 후 자막·음악 편집까지 한 앱에서 끝낼 수 있는 게 장점입니다.

사용 방법

  1. capcut.com 웹 또는 CapCut PC/모바일 앱 로그인 (200크레딧 지급)
  2. AI 비디오/Seedance 2.5 도구 선택
  3. 스크립트·프롬프트 입력 후 생성 → 편집기에서 바로 다듬어 내보내기
