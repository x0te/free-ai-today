제약·메모
영상 생성·슈퍼에이전트는 크레딧 소모가 커서 100크레딧이 금방 소진. 유료(Plus/Pro)는 핵심 AI Chat·AI Image 모델을 크레딧 차감 없이(한도 내) 사용. 정확한 무료 사용 가능 모델명은 공식 문서에 명시되지 않음.

소개

여러 LLM과 이미지·영상 모델을 묶어 채팅, 리서치, 슬라이드·문서 생성까지 해주는 '올인원 에이전트' 서비스. 무료 계정은 매일 크레딧을 받아 모든 기능을 조금씩 써볼 수 있다. 한국을 핵심 시장으로 공략 중이라 한국어 사용감이 좋은 편.

사용 방법

  1. genspark.ai 접속 후 Google 계정으로 가입
  2. AI Chat 또는 Super Agent 선택 후 요청 입력
  3. 우측 상단 크레딧 잔액으로 남은 양 확인

Genspark의 다른 무료 기능
