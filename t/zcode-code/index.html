소개

중국 Z.ai(즈푸)가 만든 GLM 공식 데스크톱 코딩 에이전트(macOS·Windows, Linux 베타)입니다. 앱은 무료이고, 첫 실행 때 Z.ai 계정을 연결하면 신규 사용자에게 5일 체험이 주어져 GLM-5.3·GLM-5-Turbo를 일일 할당량 안에서 쓸 수 있습니다. 체험이 끝나면 GLM Coding Plan(정가 월 $18, 현재 할인가 $12.6부터) 구독이나 자체 API 키가 필요합니다.

사용 방법

  1. zcode.z.ai에서 데스크톱 앱 설치
  2. 첫 실행 때 Z.ai 계정 연결 (5일 체험 시작)
  3. 체험 기간 중 GLM-5.3 또는 GLM-5-Turbo로 작업
