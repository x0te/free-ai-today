소개

텐센트 클라우드의 AI 코딩 IDE·CLI 국제판입니다. 무료 플랜에 월 100크레딧이 기본으로 나오고, 기간 한정 프로모션으로 하루 한 번이라도 대화하면 다음 날 30크레딧이 추가됩니다. 프로모션 동안에는 무료 플랜도 모든 모델을 고를 수 있고 코드 자동완성이 무제한입니다.

사용 방법

  1. codebuddy.ai에서 가입 (250크레딧 지급) 후 IDE 또는 CLI 설치
  2. 매일 한 번 이상 채팅해 다음 날 30크레딧 활동 보상 받기
  3. codebuddy.ai 프로필 → Usage에서 남은 크레딧 확인
