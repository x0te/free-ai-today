소개

Codebuff 팀(YC)이 만든 광고 기반 무료 코딩 에이전트입니다. 터미널 CLI·데스크톱 앱·웹 앱 빌더·GitHub 저장소용 Cloud·채팅을 구독·크레딧·API 키 없이 쓸 수 있고, 작업 중 텍스트 광고가 붙습니다. 전체 접근 지역에서는 GLM 5.3 Flash·DeepSeek V4.1 Flash·MiMo 2.6 Flash·Solar 모델을 세션 차감 없이 쓰고, 그 외 지역과 VPN 사용자는 하루 25(VPN 20) Freebucks 안에서 씁니다.

사용 방법

  1. 터미널에서 npm install -g freebuff 실행 (또는 freebuff.com에서 데스크톱 앱 설치)
  2. 프로젝트 폴더에서 freebuff 실행 후 로그인
  3. 모델 선택에서 GLM 5.3 Flash·DeepSeek V4.1 Flash 등 세션 차감 없는 모델 고르기
