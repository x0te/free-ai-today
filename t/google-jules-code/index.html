소개

Jules는 GitHub 저장소를 클라우드 가상머신에 복제해 계획 수립, 코드 수정, 테스트 실행, 풀 리퀘스트 생성까지 비동기로 처리하는 Google의 코딩 에이전트입니다. 작업을 맡겨 두고 다른 일을 하다가 결과만 검토하면 되는 방식이라 버그 수정·테스트 작성·의존성 업데이트 같은 반복 작업에 유용합니다. 무료 한도가 경쟁 비동기 에이전트 대비 넉넉한 편입니다.

사용 방법

  1. jules.google 접속 후 Google 계정으로 로그인
  2. GitHub 계정을 연결하고 작업할 저장소 선택
  3. 할 일을 입력하면 Jules가 계획을 제시, 승인 후 실행
  4. 완료된 변경 사항(diff)을 검토하고 PR 생성
